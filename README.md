# Тестовое задание для Яндекса

Лендинг «Клуб четырех коней», выполненный в рамках тестового задания для Яндекса.

## Стек

- HTML
- CSS
- Vanilla JavaScript

Без библиотек и фреймворков.

## Как запустить

Самый простой способ:

1. Откройте файл `index.html` в браузере.

Также можно запустить через локальный сервер, например:

```bash
npx serve .
```

После запуска откройте адрес, который появится в терминале.

## Структура

- `index.html` — разметка страницы
- `styles.css` — стили и адаптив
- `script.js` — интерактив: карусели, бегущая строка, анимации
- `img/` — изображения проекта
